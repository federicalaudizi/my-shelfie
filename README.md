## How to execute the JAR

In order to start the JAR, input the following:

- To start the client: `java -jar /path/to/jarfile.jar -c`
- To start the server: `java -jar /path/to/jarfile.jar -s`
- To show the help menu: `java -jar /path/to/jarfile.jar -h`
